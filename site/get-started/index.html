How the system works,
in one paragraph.

Tokens live as JSON in a single GitHub repo. A build script generates CSS variables, a TypeScript token map, and a Figma-shaped JSON from the same source. Components consume those tokens — never raw values. Figma Variables, Text Styles, and the entire component library in Figma are kept in sync by a custom plugin that pulls from the same source. Change a token, push, and the same value flows to web, native, and design in one motion.
