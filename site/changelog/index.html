Notable changes to the design system. Reverse chronological — newest first.

v0.5 May 2026
Feature

Showcase site launched. Get started guides for designers, developers, and PMs. Principles page. Placeholders for Foundations, Components, and Patterns content (with links to Storybook and Figma in the meantime).

v0.4 May 2026
Feature Breaking

Full typography binding in Figma. Added $extensions[design-system.figma-value] overrides for fontFamily and fontWeight tokens so Figma Variables hold values it can use as actual font assets (Inter, Medium, etc.). Created 18 Figma Text Styles, one per typography role, with all four axes (fontFamily / fontStyle / fontSize / lineHeight) bound to the underlying Variables.

Breaking: font-weight Variables are now STRING type instead of FLOAT. The plugin auto-migrates on next Sync tokens — manual cleanup not required, but components bound to the old FLOAT variables need a regenerate.

v0.3 May 2026
Feature

Custom Figma plugin shipped. Four one-click sync features: Sync tokens (creates 481 Variables across 4 Modes), Sync Text Styles (18 styles), Generate Foundations pages (5 reference pages), Generate components (16 components, ~2,400 variants).

Replaces Tokens Studio Pro for our workflow. Reads directly from tokens.figma-variables.json on GitHub.

v0.2 May 2026
Feature

Responsive web extensions. Breakpoint primitives, fluid clamp() display sizes (CSS only — Figma keeps static ceilings), @media (hover: hover) guards on every component's :hover rule, density attribute support, Storybook Theme + Density toolbars, Chromatic four-corner snapshot matrix.

v0.1 May 2026
Feature

Initial release. 481 tokens (primitives, semantics, components) authored as W3C JSON. Zero-dep Node build script emits CSS, TypeScript, and Figma Variables JSON. CI guards reject hand-edits to generated files. 16 React components with full a11y, dark mode, RTL, reduced-motion support. Storybook with stories for every variant.
