How to scope a build so AI delivers

  • Always describe the user, the action, and the success state.
  • Name 1–3 components you expect in the result.
  • Specify which states matter (loading, empty, error, RTL).
  • Decline the first answer that looks close; ask for three variations.

Anti-patterns

  • Treating Cowork as a designer — it produces prose and prototypes, not decisions.
  • Skipping the Spec stage of the pipeline.
  • Shipping the first prototype as "design done."
