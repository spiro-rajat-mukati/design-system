For designers

The Figma library mirrors the code library one-to-one. Anything you can build in Figma using these components and Text Styles will ship looking the same.

  1. Open the Figma library file

    Ask your design lead for an invite to the Design System Library file in the Kijani team. Open the file and confirm you can see the Design System Variable Collection in the right sidebar.

  2. Enable it as a Team Library in your own file

    From any working file, open the Assets panel → Libraries icon → toggle on Kijani Design System. Components, Variables, and Text Styles become available in your file's drag-and-drop assets.

  3. Try switching modes

    Select a top-level frame, click the Modes button in the right panel, and switch between Light and Dark. Every component should re-theme correctly. If anything looks off, file a bug.

  4. Apply a Text Style

    Select any text node. In the right panel, click the Typography link icon and pick a style from the Typography/ group. The fontFamily, fontStyle, fontSize, and lineHeight are all bound to tokens — change a typography token in code and your text updates here automatically.

  5. Swap in real icons

    Components like Button have grey rectangle icon slots by default. Right-click an icon slot → Swap instance → pick an icon from the Kijani icon library (also a team library you'll need to enable).

  6. Need something that isn't here?

    File a request via the RFC template on GitHub or post in #design-system. Token tweaks usually ship the same week. New components take 1-3 weeks depending on complexity. Don't fork — propose.

Conventions worth knowing

Variables and modes

Every visual value in a component is a Variable. You can override a Variable on a specific layer if you genuinely need to (and you'll see why the rest of the system disagrees with you in code review).

Modes

Web has two Modes: Light and Dark. Touch-target sizing (≥ 44px) isn't a web density Mode — it's handled in the mobile (React Native) tokens, where the iOS and Android platforms are separate.

Don't change what's published

Treat library components as immutable. If you detach an instance to "make it work for this case," that's a signal we need a new variant or a new pattern. Tell us — that's how the system gets better.
