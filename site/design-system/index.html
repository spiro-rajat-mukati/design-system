How the three layers work together.

A foundation is a token — a colour, a font size, a spacing step. Tokens are authored once and flow uniformly to CSS, React Native, and Figma Variables.

A component is a piece of UI that consumes foundations. A Button reads from button/primary/bg, which aliases color/action/primary/bg, which aliases color/brand/700. Three layers, one source of truth.

A pattern is a documented way to compose components. Patterns don't ship as code — they're recipes. "A page header is a heading + a subtitle + right-aligned actions." Designers and developers follow the recipe and produce something that fits the system.
