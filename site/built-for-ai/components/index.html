Composition rules

  • Compose from the inside out — fields → form → page.
  • Mode is inherited — never pass colour props for theming.
  • Spacing comes from layout primitives, not from margin on components.
  • Forms always use Field.

Anti-patterns AI must avoid

  • Re-implementing a component "with a tweak" — file an RFC instead.
  • Wrapping a component in extra divs to override styling — the component is missing a prop.
  • Mixing Kijani components with raw HTML controls on the same surface.
  • Using Modal as a non-modal panel — focus trap matters.
  • Stacking Tooltip on critical info — not reachable for SR / touch users.
