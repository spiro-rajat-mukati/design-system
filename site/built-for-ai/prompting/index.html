Prompt library.

Templates that reliably produce Kijani-quality output across Claude.ai, Claude Code, Cowork, Lovable, and Antigravity. Copy a template, fill in the bracketed slots, send.

Canonical version: docs/ai/prompting.md.

The project context block

A short, fixed block that goes at the top of every prompt. It tells the model to read CLAUDE.md first and lists the hard constraints (Kijani components, Kijani tokens, light and dark modes, accessibility as a build error). Full block in the canonical doc.

Patterns that produce better output

  • Tell the model where to start reading.
  • Demand a plan before code.
  • Constrain output shape, not creativity.
  • Give negative examples — what not to do.
  • Ask for the diff, not the whole file.
  • Make the model self-check against the quality bar.

Anti-patterns

  • "Just make it look nice" — there's no shared reference for "nice."
  • Pasting a screenshot without the context block — defaults to generic UI.
  • Letting the model pick a component without naming a reason.
  • Re-prompting after a bad output without naming what was wrong.
