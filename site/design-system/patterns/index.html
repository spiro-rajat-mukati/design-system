How to combine components into common UI — headers, empty states, dialogs, and form layouts. We're cataloguing the patterns Kijani uses across products and will publish them here.

Patterns library — coming next

Patterns are recipes for composition, not new components. They document the recommended way to assemble what's already in the library to solve a specific UX problem.

What this layer will contain

Once the patterns library lands, expect entries like:

  • Page header — title + subtitle + right-aligned actions
  • Empty state — illustration + message + primary action
  • Form layout — vertical Fields with primary / secondary action footer
  • Filter bar — search + dropdowns + active-filter chips
  • Pagination — page navigation with size summary
  • Section header — repeated within a page
  • Modal / Dialog — overlay with focus trap and action footer
  • List item — leading visual / title / meta / trailing action

What to do until then

Use the components directly. When you find yourself composing the same group three times across surfaces, propose it as a Pattern via the RFC template. That's how the patterns layer earns its content — proven repetition, not speculation.
