For developers

16 React components with full accessibility and light / dark mode support. Tokens flow from a single JSON source to CSS, TypeScript, and React Native.

  1. Install the package

    The package isn't published to npm yet — install from the GitHub repo directly:

    npm install rajatspiro/design-system

    Once we publish to npm, this becomes npm install @kijani/design-system. Until then, you can also clone the repo and link locally.

  2. Import the token CSS

    In your app's entry file (e.g. main.tsx):

    import "design-system/src/tokens/primitives.css";
import "design-system/src/tokens/semantics.css";
import "design-system/src/tokens/component-tokens.css";

    That gives you every CSS custom property — primitives, semantics, and component tokens. Components later in the page consume only the component tokens.

  3. Use a component

    import { Button } from "design-system";

export default function Page() {
  return (
    <Button variant="primary" size="md">
      Save changes
    </Button>
  );
}

    All components export from the package root. TypeScript types are bundled — autocomplete works out of the box.

  4. Enable theming

    Set the theme attribute on your <html> element:

    document.documentElement.setAttribute("data-theme", "dark");

    Or use the setTheme() helper:

    import { setTheme } from "design-system";
setTheme("dark");

  5. Use the TypeScript token map (for React Native or non-CSS consumers)

    import { tokens, resolveToken } from "design-system";

// Pick a value at the current theme.
const buttonHeight = resolveToken("--button-height-md", "light");
// → "44px"

Conventions worth knowing

Composition over configuration

Components like Field accept slots (children) rather than long prop lists. <Field label="..."><TextInput /></Field> beats <FieldWithInput label="..." inputValue="..." inputType="..."/>.

Logical CSS properties

Component CSS uses padding-inline-start etc., not padding-left. Drop your app inside <html dir="rtl"> — no component changes needed.

Hover guards

Every :hover rule in component CSS is wrapped in @media (hover: hover) so touch devices don't get stuck hover states.

Reduced motion

@media (prefers-reduced-motion: reduce) collapses every motion duration token to 0ms. Components inherit this without opt-in.

Where to file requests

Bug or new component? Open an issue. Token tweak (e.g. tweaking a colour value)? Open a PR against src/tokens/source/*.json — both leads review.
